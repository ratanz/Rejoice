# Rejoice Agency Website – Modern UI/UX Web Project

This project is a modern, reimagined version of a leading digital agency website, built to showcase advanced UI/UX principles, smooth scrolling, and design consistency throughout. Developed using HTML, CSS, JavaScript, and Locomotive Scroll for seamless navigation and engaging user interactions.

## ✨ Features

- Advanced, consistent UI/UX design
- Smooth, buttery scrolling with Locomotive Scroll
- Responsive and visually engaging layouts
- Modular, clean code structure

## 🚀 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- [Locomotive Scroll](https://locomotivemtl.github.io/locomotive-scroll/)

## 🛠️ Getting Started

1. Clone the repository  
   `git clone https://github.com/yourusername/rejoice-agency-website.git`
2. Open `index.html` in your browser.
